# 📝 투두리스트

HTML, CSS, JavaScript만으로 만든 간단한 할 일 관리 웹 앱입니다.

## 기능

- 할 일 추가 (추가 버튼 또는 Enter)
- 체크박스로 완료 / 미완료 전환
- 남은 할 일 개수와 전체 개수 표시

## 실행 방법

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

```
git clone https://github.com/pdsamkorea/first-claude-app.git
cd first-claude-app
```

이후 `index.html`을 더블클릭하세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `script.js` | 할 일 추가·전환·화면 렌더링 로직 |

## 참고

할 일은 메모리에만 저장되므로 페이지를 새로고침하면 사라집니다.
