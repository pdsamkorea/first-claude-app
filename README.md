# 📝 투두리스트 + 🛒 장보기

HTML, CSS, JavaScript만으로 만든 할 일 관리 · 장보기 웹 앱입니다.

## 기능

### 할 일
- 할 일 추가 (추가 버튼 또는 Enter)
- 작성일 자동 기록, 마감일 직접 지정 (마감이 지나면 빨간색 표시)
- 체크박스로 완료 / 미완료 전환, 삭제
- 미완료 먼저, 마감일 빠른 순으로 정렬
- 남은 할 일 개수와 전체 개수 표시

### 장보기
- 품목을 카테고리별로 정리 (채소, 과일, 반찬, 정육·수산, 유제품, 곡류, 양념·소스, 생필품 등)
- 품목과 카테고리를 직접 추가 · 삭제 (카테고리 이름 앞에 이모지가 없으면 자동으로 붙음)
- 이번에 살 것만 선택 → "장보러 가기"로 선택한 품목만 모아서 장바구니에 담으며 체크
- "장보기 완료" 시 선택만 초기화되고 품목 목록은 유지

모든 데이터는 브라우저의 `localStorage`에 저장되어 새로고침해도 남습니다.

## 실행 방법

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

```
git clone https://github.com/pdsamkorea/first-claude-app.git
cd first-claude-app
```

이후 `index.html`을 더블클릭하세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (할 일 / 장보기 탭) |
| `style.css` | 스타일 |
| `script.js` | 할 일, 장보기 로직과 저장 |

## 참고

데이터는 사용하는 브라우저에만 저장됩니다. 다른 기기나 다른 브라우저와는 공유되지 않으며, 브라우저 데이터를 지우면 함께 사라집니다.
